## Remaining Commercial Gaps

| # | Gap | Priority | Notes |
|---|-----|----------|-------|
| 1 | **Code signing** | HIGH | Windows SmartScreen will flag the installer as "unrecognized app" until signed with an EV Code Signing Certificate (~$300-400/year) |
| 2 | **Branded icon** | HIGH | Current icon is a placeholder gradient. Needs professional Titan POS logo design. |
| 3 | **Artifact hosting** | MEDIUM | GitHub Releases works for small deployments. Consider S3/CDN for large-scale distribution. |
| 4 | **Install smoke test** | MEDIUM | Full install/uninstall/upgrade cycle should be tested on a clean Windows VM before ship. |
| 5 | **Silent install for IT** | LOW | NSIS supports `/S` silent install but not tested. |
| 6 | **Printer driver** | LOW | Thermal printer may need driver installation. Currently uses browser `window.print()`. |
